# Setup Hinglish Guide

1. Repo folder me jao.
2. Python 3.12 ka virtual environment banao.
3. Environment activate karo.
4. Dependencies install karo (`pip install -e .[dev]`).
5. Demo run karo:

```bash
python -m recovery_tester demo --artifacts-dir artifacts
```

Aapko console me run directory, JSON report path, aur HTML report path dikhna chahiye.

Phir browser me HTML report kholo. Wahan PASS/FAIL checks aur demo scenarios clearly dikhte hain.
